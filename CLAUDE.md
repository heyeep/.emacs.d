# Rules for working in this repo

- Always use the ISO 24495 plain-language skills for user-facing text: `iso-24495-1` for replies, `iso-24495-3` and `iso-24495-5` for documents, and `iso-24495-code` when writing code.
- Never create commits or branches. Stage changes when asked, then suggest a commit message (one line, under 80 characters) or a branch name. The user makes the commit.
